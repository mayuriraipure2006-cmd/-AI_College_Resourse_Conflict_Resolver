# 🤖 AI College Resource Conflict Resolver

## 📌 Project Overview

AI College Resource Conflict Resolver is a web-based college resource scheduling system built using **Python and Flask**.

The system helps manage college resources such as **labs, seminar halls, and an auditorium** when multiple groups or events require resources at overlapping times.

It uses **priority-based scheduling, constraint checking, and heuristic scoring** to allocate suitable resources and detect scheduling conflicts.

---

## 🎯 Objectives

- Efficiently manage college resources.
- Allocate resources to different groups and events.
- Detect resource and time conflicts.
- Give priority to important events.
- Consider the user's preferred resource.
- Automatically select an available resource.
- Display successful allocations and conflicts.
- Calculate the overall scheduling success rate.
